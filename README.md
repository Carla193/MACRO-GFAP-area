# Macro de Astrogliosis (FIJI / ImageJ)

Macro para automatizar la cuantificación del área de astrogliosis en muestras cerebrales obtenidas con microscopio confocal. Incluye normalización de imágenes, aplicación de threshold, cálculo del área GFAP+ y extracción de métricas para el análisis del ictus.

## Archivo
- astrogliosis_macro.ijm — Normalización, threshold y cálculo de área GFAP+

## Tecnología
FIJI (ImageJ)
